# NYC Taxi Demand Analysis

This project analyzes NYC taxi trip data to understand taxi demand patterns based on pickup time and day.

The project focuses on:
- Hourly taxi demand
- Daily and weekly demand patterns
- Monthly trip volume
- Average trip duration by pickup hour
- Hour and weekday demand patterns

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains NYC taxi trip records, including pickup datetime and trip duration information.
